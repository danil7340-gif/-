# Project Chomba (WoW Addon 7.3.5)

Addon for tracking quest chains by chapters and locations.

## Features
- UI Window showing quests grouped by Zone and Chapter.
- Color-coded status (Green = Completed, Red = Not Completed).
- NPC names and coordinates for each quest.
- Localized in English and Russian.
- Minimap icon for quick access.

## Commands
- `/chomba` - Toggle the main window.

## Installation
Place the `ProjectChomba` folder into your `Interface/AddOns/` directory.
